# Copilot Agent Setup

## Suggested Roles
- PM Agent: planning, issue breakdown, dependency tracking
- Dev Agent: implementation and unit tests
- QA Agent: regression validation and parity checks

## Working Agreement
1. Every task must include acceptance criteria.
2. Every PR must include test evidence.
3. QA sign-off is required before merge.

## Prompt Inputs per Task
- Legacy ASP snippet(s)
- Expected behavior
- DB tables affected
- Security and audit requirements
